РИТМЫ И РЕШЕНИЯ — КАЛЕНДАРЬ 2027

Это первая рабочая версия интерактивного календаря.

КАК ОТКРЫТЬ
1. Откройте файл index.html двойным нажатием — он работает в обычном браузере без установки программ.
2. Для проверки на телефоне разместите файл на GitHub Pages или другом статическом хостинге.
3. В календаре выберите режим, раздел и дату. Нажмите на дату — справа (на телефоне ниже календаря) появится описание событий.
4. Укажите дату рождения в блоке «Мои финансовые даты», чтобы увидеть три символические даты. При необходимости поставьте галочку «Запомнить дату»; информация сохраняется только на устройстве.
5. Кнопки «Добавить день» и «Добавить весь месяц» скачивают файл .ics. Откройте его в календаре телефона/компьютера и подтвердите импорт; автоматического фонового обновления пока нет.

КАК РАЗМЕСТИТЬ НА GITHUB PAGES
1. Создайте новый репозиторий на GitHub.
2. Загрузите в корень репозитория файл index.html.
3. В Settings → Pages выберите Deploy from a branch → main → /(root) → Save.
4. Полученная ссылка будет вести на ваш календарь. Название репозитория и домен можно изменить.

ОГРАНИЧЕНИЯ ПЕРВОЙ ВЕРСИИ
- Пока есть только 2027 год, с астрономическими датами фаз Луны и затмений из указанных источников.
- Время астрономических событий установлено для Уфы, UTC+5. Для других часовых поясов даты рядом с полуночью могут отличаться.
- Подсказки по работе, психологии, красоте и отношениям — оригинальные демонстрационные примеры, автоматически распределённые по дням. Для коммерческого запуска потребуется редакционная проработка содержания.
- Личные «денежные дни» основаны на новой демонстрационной символической формуле, НЕ на формуле Ирины; они не прогнозируют доход.
- Режим «Без эзотерики» скрывает Таро, нумерологию, ритуалы и астрологические толкования, оставляя практические рекомендации и астрономию.
- Нет личного кабинета, платежей, платной подписки, автоматического обновления календаря и рассылок.
- Никакие данные не отправляются на сервер.
